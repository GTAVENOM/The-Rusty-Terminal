Cross-Platform Native
💻

Windows & macOS Native

Built for developers collaborating across OS boundaries. Full native support for Windows (PowerShell & cmd.exe) and macOS (zsh & bash) with identical keybindings and safety gates.

Sub-1GB Neural Engine
⚡

Smart Sub-1GB AI Model

Powered by Qwen2.5-Coder-1.5B GGUF (~980MB). Over 3x higher reasoning intelligence for open-ended natural English sentences, strictly under 1GB storage. Zero cloud requirement.

Dynamic AI Reasoning
🧠

Zero Fixed Rulebooks

Accepts ANY arbitrary English prompt (e.g. "pull ubuntu latest image", "increase pods", "give full permissions to coding.c", "install express with npm") and generates executable commands with dynamic safety tiering.

🛡️

3-Tier Command Safety Gate

Tier 1 Read-Only commands auto-execute. Tier 2 Idempotent commands prompt confirmation [Y/n]. Tier 3 Destructive commands are displayed as [DESTRUCTIVE — reference only] read-only text and blocked from shell auto-insertion.

🩺

Bounded Error Help Engine

Pattern matches non-zero exit codes & stderr output (missing packages, port conflicts, permission denied, script syntax errors) to surface instant 1-line fix suggestions.

📄

Code Generation Agent

Natural language goals ("I want a Python script that renames files") generate code directly to files in .rusty_scratch/ with numeric collision protection (script_1.py).

🔍

Multi-Option Disambiguation

Ambiguous inputs (e.g. go to folder) automatically present a numbered choice menu ([1] cd folder/ [2] cd folder_backend/) for instant 1-click selection.

⌨️

Everywhere Autocomplete (Ctrl+V)

Live inline ghost-text via PSReadLine predictor on Windows, zsh/bash on macOS, and cmd.exe trigger list (Ctrl+V keybinding).

🗄️

3-Way Local History & Privacy

Tracks Suggested, Accepted, and Rejected commands in local SQLite (rusty.db). 100% private with zero cloud telemetry.
